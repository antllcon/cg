### 1. Математика и данные (Core Types)
* **`Transform`**: Хранит позицию, вращение и масштаб. Генерирует итоговую матрицу модели (Model Matrix) для отправки в шейдер.
* **`CameraData`**: Структура-контейнер (DTO) для матриц вида (View) и проекции (Projection), а также позиции камеры.
* **`LightData`**: DTO с параметрами света (тип, цвет, позиция, направление, интенсивность).

### 2. Абстракции видеокарты (HAL)
* **`BufferLayout`**: Описывает структуру данных вершины (например: 3 числа — координаты, 3 числа — нормали, 2 числа — текстурные координаты).
* **`IVertexBuffer`**: Интерфейс для отправки массива самих вершин в память видеокарты (VBO).
* **`IIndexBuffer`**: Интерфейс для отправки массива индексов (IBO/EBO), чтобы видеокарта не рисовала дублирующиеся вершины.
* **`IVertexArray`**: Объединяет буферы вершин, буферы индексов и их разметку (`BufferLayout`) в единый объект (VAO) для быстрой отрисовки.
* **`IShader`**: Интерфейс для работы с программами видеокарты. Позволяет включать шейдеры и прокидывать в них параметры (матрицы, цвета) через методы `Set*`.

### 3. Ресурсы сцены
* **`IMaterial`**: Управляет визуальными свойствами объекта. Хранит ссылку на шейдер (`IShader`) и параметры освещения (базовый цвет, цвет блика, сила блеска по Фонгу), чтобы перед отрисовкой автоматически прокинуть их в видеокарту.
* **`IMesh`**: Контейнер для геометрии. Прячет внутри себя `IVertexArray` (VAO со всеми вершинами и индексами) и знает точное количество индексов (`GetIndexCount`), которое нужно передать команде отрисовки.
